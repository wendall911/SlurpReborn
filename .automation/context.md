# SlurpReborn -- Project Context

## What This Is
A stopgap mod created for the 1.19.2 modpack. When an upstream mod removed the ability to drink directly from water sources, this mod restored that feature temporarily for the modpack. Now effectively superseded -- Homeostatic replaced that mod entirely, making SlurpReborn unnecessary going forward.

No plans for further development.
